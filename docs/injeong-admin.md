# 인정건설 홈페이지 관리자 (/admin)

기술 칼럼, 시공 실적, 홈 팝업을 홈페이지에서 직접 쓰고 고치는 화면입니다.

## 들어가는 법

- 주소: `https://<홈페이지 주소>/admin`
- 비밀번호: 서버 환경변수 `ADMIN_PASSWORD` (로컬은 `.env.local`)
- 로그인은 7일 유지됩니다. 비밀번호를 바꾸려면 환경변수를 바꾸고 서버를 다시 시작합니다.

## 할 수 있는 일

| 메뉴 | 기능 |
| --- | --- |
| 기술 칼럼 | 새 칼럼 쓰기, 실린 칼럼 고치기·숨기기·삭제, 고친 기존 칼럼을 원래대로 되돌리기, 대표 사진과 본문 사진 올리기 |
| 시공 실적 | 준공·시공 중 현장 추가, 고치기·숨기기·삭제, 현장 사진 올리기 |
| 팝업 | 홈 첫 화면 공지 팝업 만들기, 기간(시작·종료일)과 켜기·끄기, 사진과 버튼 링크 |

저장하면 홈페이지에 바로 반영됩니다. 코드에 들어 있는 기존 글과 실적은 지워지지 않고, 고친 내용과 숨김 목록만 따로 저장됩니다.

## 저장 위치

| 운영 방식 | 설정 | 저장 위치 |
| --- | --- | --- |
| 일반 서버 (`npm run build && npm start`, standalone) | 없음 | 서버의 `.data/injeong/` (글 JSON + 올린 사진). 백업 대상 |
| Vercel | Vercel Blob 스토어를 연결해 `BLOB_READ_WRITE_TOKEN` 설정 | Vercel Blob |

## 필요한 환경변수

| 이름 | 설명 |
| --- | --- |
| `ADMIN_PASSWORD` | 관리자 비밀번호 |
| `ADMIN_SECRET` | 로그인 쿠키 서명 키, 32자 이상 무작위 문자열 |
| `BLOB_READ_WRITE_TOKEN` | Vercel에서만. Blob 스토어 연결 시 자동으로 들어갑니다 |

## GitHub Pages 임시 주소

임시 주소(github.io)는 서버가 없는 정적 사본이라 관리자와 업로드가 빠집니다. 관리자는 실제 서버(또는 Vercel)에 올린 뒤부터 쓸 수 있습니다.
